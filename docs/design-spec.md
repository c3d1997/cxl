# 設計規格

> 三個頁面皆已實作，內容已自 2023profile 遷移完成。

## 整體風格

極簡主義 / 負空間（negative space）。參考類型：設計師個人 archive 網站（如 maxim.tur.rent）。

### 紙張質感

所有大範圍色底都疊一層噪點，讓平塗色塊帶有紙的手感：

- 左欄粉色底、右側畫布底、作品詳細頁底
- 以 SVG `feTurbulence` 產生噪點並編碼為 data URI，不需額外圖檔與請求
- 作為元素自身的 `background-image`，**不是覆蓋層** — 作品圖片與色塊疊在質感之上，不受影響
- 濃度與貼圖尺寸集中在 `_mixins.scss` 的 `paper-texture()`，調整一處即全站生效

取用的是**版面結構模式**，不是對方的視覺識別或內容 — 配色、字體、標誌需自行定義。

## 首頁（作品集）`/`

### 版面分割

```
┌──────────────────┬─────────────────────────────────────┐
│                  │  26. BARNEY LISTER │ 客戶 │ EP │2018│  ← 中繼資料列
│   左欄 35%       ├──────┬──────┬──────┬──────┬─────────┤
│                  │      │      │      │      │          │
│   大量留白       │ 作品 │ 作品 │ 作品 │ 作品 │          │  ← 作品列
│                  │      │      │      │      │          │
│                  ├──────┴──────┴──────┴──────┴─────────┤
│  ┌ 頂部：標誌    │  25. OVERSHARE     │ 客戶 │ 書 │2018│
│  └ 底部：導覽    ├──────┬──────┬──────┬──────┬─────────┤
│                  │      │      │      │      │          │
└──────────────────┴─────────────────────────────────────┘
       35%                        65%
```

### 左欄（35%）

- 主體是留白，內容集中在上下兩端，中段僅有一個功能性指示
- 頂部：姓名（2.25rem 粗體，版面的支點）＋ 職稱／英文職稱
- 中段：作品清單的捲動位置指示（如 `08 / 17`），僅作品集頁有值
- 底部：分三組 —— 導覽、聯絡、版權，各組有 11px 的小標籤
- 文字極小、全大寫、字距略寬
- 底色與右側區塊不同（參考圖用淡粉色），形成色塊分割

### 右欄（65%）— 書架式列表

- 作品以「列」為單位由上往下堆疊，像書架分層
- 每列上方一條**中繼資料列**（3 欄，`2fr 1fr 1fr`），欄位對齊下方圖片：
  | 欄位 | 範例 |
  |---|---|
  | 編號 + 標題 | `13. 星達威鉑數位整合行銷` |
  | 狀態 | `在線` / `已下架（可查看網頁截圖）` / `無法提供畫面` |
  | 技術 | `SCSS・HTML5・jQuery` |

  中繼資料字級 14px（`$font-size-work-meta`）。欄寬比例 `1.43fr 1fr 1.47fr`，依現有內容最長字串量測而得（約需 290 / 203 / 299 px）。三欄合計需約 792px，換算視窗約 1220px，故 `$breakpoint-lg: 1240px` 以下收起技術欄，避免三欄同時被截斷。**日後新增更長的標題或技術清單時，需重新量測並調整這兩個值。**
- 每列一張橫向網站截圖，以 16:9 完整呈現（網站截圖本身是橫的，裁成方形會切掉大半版面）
- 列與列之間以細髮絲線分隔
- 編號由大到小（新作在上）
- 排列順序：有畫面的作品在前（現職 → 2023 年前），後台專案集中在最後（現職 → 2023 年前）
- 圖片延伸至畫面右緣，不留外邊距

### 捲動位置指示

左欄中段唯一的元素。**功能性而非裝飾** —— 25 件作品的長清單需要位置感。

- 判定線為視窗上緣往下 20%，越過此線的最後一列即為目前位置
- 以捲動事件加 `requestAnimationFrame` 節流計算，不用 IntersectionObserver：後者在大幅跳躍捲動時，中間掠過的列不會產生事件
- 補零寬度隨總數變動（`08 / 17`、`1 / 8`），並使用 `tabular-nums` 等寬數字避免捲動時左右跳動
- 清單在右側內容欄、指示在左側側欄，分屬不同元件樹分支，以 `useWorkProgress` 組合式函式傳遞狀態
- 離開作品集頁時重設，其他頁面不顯示

### 作品分類書籤

直書書籤，浮在作品清單左緣之外（突進左欄的粉色留白）：網頁設計 / 後台系統，各自標示數量。

```
  ╭──┐
  │網│ │ 25. LINE PARKING      待補畫面
  │頁│ │┌─────────────────────────────┐
  │17│ ││                             │
  ╰──┘ │└─────────────────────────────┘
   ╭──┐│ 24. LINE HOTEL        待補畫面
   │後│││┌────────────────────────────┐
   │台│││                             │
   ╰──┘│└────────────────────────────┘
```

- `writing-mode: vertical-rl` 直書，無框線，圓角只給左端
- 文字上下左右置中（直書下主軸為垂直、交錯軸為水平，兩軸皆 center）
- 全部書籤**等寬**，選取時不變寬；第一張切齊畫面最上方
- **未選取 = 左欄粉色**（與側欄同色，像仍收在粉色那一側）
- **選取 = 右欄白色**，陰影加深
- 陰影分兩段：未選取 `-1px 1px 4px / 0.08`、選取 `-3px 2px 12px / 0.22`
- **右側不投影** — `box-shadow` 的模糊會往四面擴散，以 `clip-path: inset(-20px 0 -20px -20px)` 將右緣切齊，其餘三邊給負值讓陰影溢出
- 容器寬度為 0、清單絕對定位 `right: 0`，**每張書籤的右緣都貼齊作品清單左緣**；作品清單維持滿版
- 文字字重 500、選取時 700；字色較一般次要文字再深一階（`$color-secondary-strong`）
- 數字以 `text-combine-upright: all`（縱中橫）維持水平直立，否則直書下會旋轉 90 度
- 過渡僅保留陰影，其餘狀態變化即時切換
- `position: sticky`，捲動長清單時仍可切換
- 無「全部」選項；預設顯示清單第一個分類（網頁設計），網址帶入未知值時亦退回該分類
- 編號維持作品的固定編號，篩選後不重新計算（編號是身分，不是位置）
- 窄螢幕沒有左側空間，改回橫向排列並改用底線標示選取

### 頁面切換

純文字連結，14px，作用中者加底線（`text-underline-offset: 0.25em`），不加框線與填色 — 維持負空間的輕量調性。點擊區 44px。

清單由 `router.options.routes` 過濾 `meta.title` 產生 — 新增路由只要填 `meta.title`，tab 會自動出現，不需改元件。

## 作品詳細頁 `/work/:slug`

點選索引頁任一列作品後進入，佔滿整個畫面（不顯示側欄）。

```
┌──────────────────┬─────────────────────────────┐
│                  │                    (Close)  │  ← 頂端留白帶
│  004             ├─────────────────────────────┤
│  專案名稱 D       │                             │
│                  │          大圖 01            │
│  客戶  客戶名稱   │                             │
│  類型  WEB       ├─────────────────────────────┤
│  年份  2025      │                             │
│                  │          大圖 02            │
│  說明文字……       │                             │
│                  ├─────────────────────────────┤
└──────────────────┴─────────────────────────────┘
       35%                      65%
```

- 左欄 `position: sticky`，捲動大圖時說明留在畫面上
- 大圖比例 4:3（索引頁為 1:1），上下堆疊無間距
- 右上角 `(Close)` 回到索引頁；**Esc 鍵**同樣可關閉
- 頂端 3.5rem 留白帶，避免 `(Close)` 疊在深色圖片上不可辨識
- 查無對應 slug 時顯示提示與返回連結
- 窄螢幕改為上下堆疊（文字在上、大圖在下）

## 個人介紹 `/about`

沿用左欄側欄，內容在右側 65%。延續索引頁語彙：髮絲線分隔、左側 11px 標籤欄、右側內容。

```
┌──────────────────┬─────────────────────────────┐
│                  │                             │
│                  │   這裡放一段自述……            │  ← 22px，上下大留白
│   （側欄）        │                             │
│                  ├─────────────────────────────┤
│                  │  經歷   2023—    職稱        │
│                  │                 公司名稱     │
│                  ├─────────────────────────────┤
│                  │  學歷   2015—19  科系        │
│                  ├─────────────────────────────┤
│                  │  技能   前端    Vue 3、…     │
│                  ├─────────────────────────────┤
│                  │  聯絡   EMAIL / GITHUB      │
└──────────────────┴─────────────────────────────┘
```

- 自述置於所有分隔線之上，上下各留 4rem／6rem，作為視覺起點
- 標籤欄固定 8rem，期間欄固定 7rem，多筆經歷的年份對齊成一直線
- 單位名稱使用次要文字色 `$color-secondary`（對比 4.85:1，通過 WCAG AA）
- 內容全部來自 `src/data/profile.js`，改文字不必動版面
- 窄螢幕收成單欄，標籤與期間改為堆疊

## 已定案

| 項目 | 決定 |
|---|---|
| 配色 | 左欄 `#eddce5` 淡粉、右欄 `#f4f4f4`、字色 `#111`、髮絲線 `#c9c9c9` |
| 左欄行為 | `position: sticky; top: 0; height: 100vh`，右側捲動時不動 |
| 字體 | 系統無襯線堆疊（Helvetica Neue / Arial / Noto Sans TC），未載入外部字型 |
| 窄螢幕 | < 768px 時上下堆疊，左欄轉為頂部橫列，網格改 2 欄，中繼資料僅留標題與年份 |
| 每列圖片數 | 每列一張大橫圖（16:9），無圖片者以色塊代替 |

所有數值集中在 `src/assets/styles/_variables.scss`，調整配色或欄數改該檔即可。
