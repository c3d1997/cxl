# 設計規格

> 三個頁面皆已實作，內容已自 2023profile 遷移完成。

## 整體風格

極簡主義 / 負空間（negative space）。參考類型：設計師個人 archive 網站（如 maxim.tur.rent）。

取用的是**版面結構模式**，不是對方的視覺識別或內容 — 配色、字體、標誌需自行定義。

## 首頁（作品集）`/`

### 版面分割

```
┌──────────────────┬─────────────────────────────────────┐
│                  │  26. BARNEY LISTER │ 客戶 │ EP │2018│  ← 中繼資料列
│   左欄 35%       ├──────┬──────┬──────┬──────┬─────────┤
│                  │      │      │      │      │          │
│   大量留白       │ 作品 │ 作品 │ 作品 │ 作品 │          │  ← 作品列
│                  │      │      │      │      │          │
│                  ├──────┴──────┴──────┴──────┴─────────┤
│  ┌ 頂部：標誌    │  25. OVERSHARE     │ 客戶 │ 書 │2018│
│  └ 底部：導覽    ├──────┬──────┬──────┬──────┬─────────┤
│                  │      │      │      │      │          │
└──────────────────┴─────────────────────────────────────┘
       35%                        65%
```

### 左欄（35%）

- 主體是留白，只在**上下兩端**放內容，中間完全空
- 頂部：標誌 / 名字
- 底部：頁面切換連結（作品集／個人介紹）、聯絡方式，之後可再加外部連結
- 文字極小、全大寫、字距略寬
- 底色與右側區塊不同（參考圖用淡粉色），形成色塊分割

### 右欄（65%）— 書架式列表

- 作品以「列」為單位由上往下堆疊，像書架分層
- 每列上方一條**中繼資料列**（3 欄，`2fr 1fr 1fr`），欄位對齊下方圖片：
  | 欄位 | 範例 |
  |---|---|
  | 編號 + 標題 | `13. 星達威鉑數位整合行銷` |
  | 狀態 | `在線` / `已下架（可查看網頁截圖）` / `無法提供畫面` |
  | 技術 | `SCSS・HTML5・jQuery` |
- 每列一張橫向網站截圖，以 16:9 完整呈現（網站截圖本身是橫的，裁成方形會切掉大半版面）
- 列與列之間以細髮絲線分隔
- 編號由大到小（新作在上）
- 圖片延伸至畫面右緣，不留外邊距

### 頁面切換

純文字連結，14px，作用中者加底線（`text-underline-offset: 0.25em`），不加框線與填色 — 維持負空間的輕量調性。點擊區 44px。

清單由 `router.options.routes` 過濾 `meta.title` 產生 — 新增路由只要填 `meta.title`，tab 會自動出現，不需改元件。

## 作品詳細頁 `/work/:slug`

點選索引頁任一列作品後進入，佔滿整個畫面（不顯示側欄）。

```
┌──────────────────┬─────────────────────────────┐
│                  │                    (Close)  │  ← 頂端留白帶
│  004             ├─────────────────────────────┤
│  專案名稱 D       │                             │
│                  │          大圖 01            │
│  客戶  客戶名稱   │                             │
│  類型  WEB       ├─────────────────────────────┤
│  年份  2025      │                             │
│                  │          大圖 02            │
│  說明文字……       │                             │
│                  ├─────────────────────────────┤
└──────────────────┴─────────────────────────────┘
       35%                      65%
```

- 左欄 `position: sticky`，捲動大圖時說明留在畫面上
- 大圖比例 4:3（索引頁為 1:1），上下堆疊無間距
- 右上角 `(Close)` 回到索引頁；**Esc 鍵**同樣可關閉
- 頂端 3.5rem 留白帶，避免 `(Close)` 疊在深色圖片上不可辨識
- 查無對應 slug 時顯示提示與返回連結
- 窄螢幕改為上下堆疊（文字在上、大圖在下）

## 個人介紹 `/about`

沿用左欄側欄，內容在右側 65%。延續索引頁語彙：髮絲線分隔、左側 11px 標籤欄、右側內容。

```
┌──────────────────┬─────────────────────────────┐
│                  │                             │
│                  │   這裡放一段自述……            │  ← 22px，上下大留白
│   （側欄）        │                             │
│                  ├─────────────────────────────┤
│                  │  經歷   2023—    職稱        │
│                  │                 公司名稱     │
│                  ├─────────────────────────────┤
│                  │  學歷   2015—19  科系        │
│                  ├─────────────────────────────┤
│                  │  技能   前端    Vue 3、…     │
│                  ├─────────────────────────────┤
│                  │  聯絡   EMAIL / GITHUB      │
└──────────────────┴─────────────────────────────┘
```

- 自述置於所有分隔線之上，上下各留 4rem／6rem，作為視覺起點
- 標籤欄固定 8rem，期間欄固定 7rem，多筆經歷的年份對齊成一直線
- 單位名稱使用次要文字色 `$color-secondary`（對比 4.85:1，通過 WCAG AA）
- 內容全部來自 `src/data/profile.js`，改文字不必動版面
- 窄螢幕收成單欄，標籤與期間改為堆疊

## 已定案

| 項目 | 決定 |
|---|---|
| 配色 | 左欄 `#eddce5` 淡粉、右欄 `#f4f4f4`、字色 `#111`、髮絲線 `#c9c9c9` |
| 左欄行為 | `position: sticky; top: 0; height: 100vh`，右側捲動時不動 |
| 字體 | 系統無襯線堆疊（Helvetica Neue / Arial / Noto Sans TC），未載入外部字型 |
| 窄螢幕 | < 768px 時上下堆疊，左欄轉為頂部橫列，網格改 2 欄，中繼資料僅留標題與年份 |
| 每列圖片數 | 每列一張大橫圖（16:9），無圖片者以色塊代替 |

所有數值集中在 `src/assets/styles/_variables.scss`，調整配色或欄數改該檔即可。
